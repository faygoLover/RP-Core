# RP Core

Общая основа семейства RP-модов для ролевого сервера на **Minecraft 1.20.1 (Forge)**. Сам по себе ничего не меняет
в игре: он нужен, чтобы моды семейства работали вместе и не зависели друг от друга. Каждый мод требует только RP Core
и полностью раскрывается, когда рядом стоят остальные.

## Моды семейства
| Мод | Что делает |
|---|---|
| [RP Perks](https://github.com/faygoLover/RP-Perks) | перки персонажа и навыки 0–10 |
| [RP Stamina](https://github.com/faygoLover/RP-Stamina) | выносливость |
| [RP Medicine](https://github.com/faygoLover/RP-Medicine-Health-revork-) | детальная медицина вместо ванильного здоровья |
| [RP Culinary](https://github.com/faygoLover/RP-Culinary) | питание: калории, жажда, вес, готовка |
| [RP PDA](https://github.com/faygoLover/RP-PDA-and-communications) | КПК-мессенджер и речь рядом |

## Что даёт RP Core
- **Навыки и черты персонажа.** Один мод их ведёт (RP Perks), остальные спрашивают у Core. Без RP Perks моды
  считают, что навыков нет, и работают «как на максимальном уровне».
- **Общий HUD.** Полоски и значки всех модов семейства рисуются одним слоем и двигаются в одном редакторе.
- **Связи между модами:** тело (RP Medicine), питание (RP Culinary), нагрузка (RP Stamina), состояние «без сознания».
  Если нужного мода нет, остальные просто обходятся без него.

## Установка
1. Minecraft **1.20.1**, **Forge 47** или новее, Java 17.
2. Положите `rpcore-<версия>.jar` в папку `mods` — **и на сервере, и у каждого игрока**.
3. Добавьте нужные моды семейства.

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| `/rpcore` | все | какие моды семейства установлены и кто ведёт навыки |
| `/rpcore skill <игрок> <навык> [уровень\|reset]` | ГМ (права 2) | посмотреть или выставить уровень навыка 0–10; `reset` — убрать уровень ГМа |
| `/rphud` | все | редактор HUD: перетаскивайте элементы мышью, колесо — масштаб |

Навыки: `medicine`, `cooking`, `short_arms`, `long_arms`, `heavy_arms`, `explosives`, `melee`, `strength`, `fitness`.

## Настройки
- `config/rpcore-common.toml` — исправления утечек памяти в чужих модах (Tacz Attribute Add, Sanity: Descent Into
  Madness). Срабатывают, только если такой мод установлен; можно выключить.
- `config/rpcore-hud.json` — раскладка HUD у игрока (пишется редактором `/rphud`).
