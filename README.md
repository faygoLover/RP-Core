# RP Core

Общая основа семейства RP-модов для ролевого сервера на **Minecraft 1.20.1 (Forge)**. Сам по себе ничего не меняет
в игре: он нужен, чтобы моды семейства работали вместе и не зависели друг от друга. Каждый мод требует только RP Core
и полностью раскрывается, когда рядом стоят остальные.

## Моды семейства
| Мод | Что делает |
|---|---|
| [RP Perks](https://github.com/faygoLover/RP-Perks) | перки персонажа и навыки 0–10 |
| [RP Stamina](https://github.com/faygoLover/RP-Stamina) | выносливость |
| [RP Medicine](https://github.com/faygoLover/RP-Medicine-Health-revork-) | детальная медицина вместо ванильного здоровья |
| [RP Culinary](https://github.com/faygoLover/RP-Culinary) | питание: калории, жажда, вес, готовка |
| [RP PDA](https://github.com/faygoLover/RP-PDA-and-communications) | КПК-мессенджер и речь рядом |

## Что даёт RP Core
- **Навыки и черты персонажа.** Один мод их ведёт (RP Perks), остальные спрашивают у Core. Без RP Perks моды
  считают, что навыков нет, и работают «как на максимальном уровне».
- **Общий HUD.** Полоски и значки всех модов семейства рисуются одним слоем и двигаются в одном редакторе.
- **Связи между модами («розетки»):** тело (RP Medicine), питание (RP Culinary), выносливость и нагрузка
  (RP Stamina), состояние «без сознания». Если нужного мода нет, остальные просто обходятся без него. На каждую
  розетку — один мод: второй такой же не заменяет первого (в лог пишется, кто с кем столкнулся).
- **Время RP** (`/rptime`): ведущий останавливает и пускает время тела, прокручивает сон и ожидание.
- **Фото игроков:** портрет по скину для медкарты и КПК. Сервер сам просит снимок у клиента, хранит его в мире
  (`<мир>/rpcore/photos/`) и раздаёт игрокам.
- **Общий список команд** всех модов семейства: `/rpcore commands`.
- **Правило:** ванильной сытостью владеет мод питания (RP Culinary), остальные моды её не трогают.

## Установка
1. Minecraft **1.20.1**, **Forge 47** или новее, Java 17.
2. Положите `rpcore-<версия>.jar` в папку `mods` — **и на сервере, и у каждого игрока**.
3. Добавьте нужные моды семейства.

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| `/rpcore` | все | какие моды семейства установлены и кто ведёт навыки |
| `/rpcore commands [мод]` | все | команды всех модов семейства (видны только доступные вам) |
| `/rpcore skill <игрок> <навык> [уровень\|reset]` | ГМ (права 2) | посмотреть или выставить уровень навыка 0–10; `reset` — убрать уровень ГМа |
| `/rphud` | все | редактор HUD: перетаскивайте элементы мышью, колесо — масштаб |
| `/rptime` | все | идёт ли время RP |
| `/rptime start\|stop` | ГМ | пустить или остановить время RP (если оно включено в настройках) |
| `/rptime sleep <время> <игроки> [all\|wounds\|food]` | ГМ | прокрутить время во сне: голод медленнее, раны заживают, выносливость полная; мир не меняется |
| `/rptime skip <время> <игроки> [all\|wounds\|food]` | ГМ | то же бодрствуя |

Время: `8h`, `30m`, `1h30m`, `45s` или число часов (`2.5`), не больше недели. `all` — всё (по умолчанию),
`wounds` — только раны, `food` — только голод.

Навыки: `medicine`, `cooking`, `short_arms`, `long_arms`, `heavy_arms`, `explosives`, `melee`, `strength`, `fitness`.

## Настройки
- `config/rpcore-common.toml`:
  - `commands.debug_commands` — отладочные команды модов семейства (по умолчанию выключены);
  - `photo.min_interval_seconds` — фото игрока не чаще раза в столько секунд (60);
  - `rptime.enabled` — время RP. Выключено (по умолчанию) — время идёт всегда. Включено — после запуска сервера
    время стоит, пока ведущий не скажет `/rptime start`: голод не тратится, раны не заживают.
- Исправления утечек памяти в чужих модах (Tacz Attribute Add, Sanity) переехали в отдельный мод **RP Fixes**.
- `config/rpcore-hud.json` — раскладка HUD у игрока (пишется редактором `/rphud`).
