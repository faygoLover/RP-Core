# «ГМские штуки» и пустая рука — RP Core 0.8.0 (23.10.2026)

Запрос Alex 22–23.10: своя вкладка креатива для мелких модов семейства, невидимая пластина, держатели предметов,
режимы пустой руки. Порталы — отдельный мод RP Portals (`Claude Code/RP Portals`).

## Вкладка «RP: разное» (`rpcore:misc`, `RpCoreAPI.MISC_TAB`)
Пластина, два держателя, валик FL Tint (fltint 1.0.1 кладёт его сюда, если Core есть), порталы RP Portals.
Видимость — как у всех предметов семейства (замок Core: `rpportals` и `fltint` добавлены в список).

## Общее для ГМских блоков
- Метки ведущего — тег `rpcore:gm_markers` (свои предметы + предметы RP Portals). С меткой в руке: контуры всех
  таких блоков в радиусе 48 (цвет по типу) и подписи вблизи; блок можно выделить и сломать; ПКМ меткой — окно настроек.
- Без метки: рамки выделения нет, пластину вообще не выделить.
- Не ломаются ничем, кроме ведущего в творческом; поршни не двигают; без добычи.
- Окно настроек — `GmSchema` (поля, условия видимости, кнопки-помощники), сервер проверяет права (`gm_permission_level`)
  и пределы. Другие моды регистрируют свою схему: `GmSchema.register(block, schema)`.
- Именованные точки `RpAnchors` (в мире `data/rpcore_anchors.dat`): пластина/портал с именем — точка прибытия.

## Невидимая пластина (`rpcore:hidden_plate`)
Без модели, коллизии, звука. Каждая сущность срабатывает отдельно при наступании («паровозик» проходит сразу),
сошла — отпускает в тот же тик. Настройки: имя, кого замечает (игроки / без прав ГМа / все живые), действие (ничего /
телепорт на координаты / к точке по имени / команда с правами ≤ прав записавшего), не менять взгляд, прибывать тем же
строем, пауза на сущность, красный камень (пока стоят / нет / импульс), сила, длина импульса, щелчок. Кнопка «Цель —
моё место». После переноса сущность `cooldown` тиков не замечают другие пластины и порталы.

## Держатели (`rpcore:wall_holder`, `rpcore:vacuum_holder`)
Настенный — как рамка, сломали опору — предмет выпадает. Сферический держатель в вакууме — висит в центре, опора
не нужна. ПКМ — забрать предмет целиком (со всеми данными), держатель пропадает (или предмет возвращается через N с).
Ведущий кладёт предмет ПКМ по пустому держателю (весь стак; в творческом — копию). Настройки: вид (плоско / как
выброшенный / в натуральную величину), размер, поворот, наклон, вращение, покачивание, коллизия, кто может взять.

## Пустая рука
`config/rpcore-client.toml` → `[hand] empty_hand`: ALWAYS, WITH_ITEM, ITEM_AND_ACTION (по умолчанию: рука с предметом
и во время удара, карабканья, плавания, ползком). Клавиша «Пустая рука» (F7) перебирает режимы.

## Не проверено в игре.

# Эффекты «Красные глаза» и «Помехи» — RP Core 0.8.1 (23.10.2026)
Частиц у носителя нет (зелье даёт видимый эффект — сервер в конце тика заменяет его таким же без частиц, значок
остаётся). Ванилла сообщает эффекты только самому игроку, поэтому Core рассылает «кто под эффектом» всем видящим
(`EffectSync`, пакет `EffectPackets.State`, канал Core VERSION 6).
- **Красные глаза** (`rpcore:red_eyes`): на лице два светящихся красных глаза с ореолом (`RenderType.eyes` —
  светятся в темноте и с шейдерпаком), в шлеме — перед шлемом. Места глаз — как у скина Стива.
  Зелье: неловкое + светящийся чернильный мешок → 3 мин; + красная пыль → 8 мин.
- **Помехи** (`rpcore:interference`): на носителе ничего; у остальных экран рябит (зерно, дрожь строк, разрывы, сдвиг
  цветов, бегущая полоса, скан-линии), сила — от расстояния до ближайшего носителя, радиус 12 блоков × уровень.
  Свой проход после мира (не слот постэффекта игры — его держит RP Medicine). Зелье: неловкое + осколок аметиста →
  3 мин; + пыль → 8 мин; + светокаменная пыль → «Помехи II» 1,5 мин (радиус 24).
- Команда: `/effect give <игрок> rpcore:red_eyes|rpcore:interference <секунды> [уровень] true`.
